# AnimForge — Roblox Animation ID Manager PWA

PWA statis, offline-first, tanpa Supabase, Node.js, npm, backend, atau database online.

## Menjalankan
- Cara paling mudah: buka `index.html` untuk memakai tool.
- Agar fitur Install PWA dan Service Worker aktif, host folder ini pada HTTPS/static hosting.
- Data mapping disimpan di LocalStorage browser.
- Export/Import memakai JSON.

## Catatan
Generator menghasilkan mapping `AnimationId` untuk project Roblox yang kamu kontrol. Ini bukan alat untuk bypass ownership, permission, moderation, atau keamanan Roblox.
